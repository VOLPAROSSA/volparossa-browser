VOLPAROSSA Browser — artwork and upstream credits

The original VOLPAROSSA mark, shared typography, navigation and website theme
come from VOLPAROSSA/volparossa.github.io, theme 1.0.3 at commit
d1900a7928dd31fcf70e07bbec60f3be2edd5348. The export is unchanged.
Font notices are in assets/fonts/; the Octicons GitHub mark notice is in
assets/icons/OCTICONS-LICENSE.txt.

The five station illustrations were generated for this page with image_gen,
using the user-provided updated station reference. They are metaphors, not
screenshots or evidence of a working distributed browser. Responsive crops
and compressed exports preserve the untouched masters in the source repository.
No reference mockup is used as a complete website section.
