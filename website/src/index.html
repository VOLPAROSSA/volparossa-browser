The shared brain,
beside every page.

Cooperating agents. Shared models. Your chosen context.

Target experience · Integration in development

VOLPAROSSA is building a shared brain that can distribute suitable work across participating devices, combine agent results and improve reusable models together. Browser is designed to bring that intelligence into Firefox’s AI sidebar, beyond the computing power of one device.

  1. 01

    Choose context

    Ask a question and choose the page content relevant to the task.

  2. 02

    Connect through Core

    Core coordinates suitable agents and models within the task’s permissions, protection requirements and available resources.

  3. 03

    Receive the answer

    Bring the result back into the browser, with visible progress and a way to cancel.

How the shared brain is intended to work

{{network_icon}}

Share suitable work

Use compatible agents and compute across participating devices.

{{combine_icon}}

Combine useful results

Bring work together and assess the result, rather than treating every response as correct.

{{improve_icon}}

Improve shared models

Evaluate and exchange eligible model improvements using authorised data.

Participating devices keep their owners’ work first; shared tasks use suitable available resources.

{{shield_icon}}

Private context requires protected execution and appropriate permissions. Reading a page does not authorise publishing it or using it for training.

Flexible access

Allow ordinary Internet access when VOLPAROSSA is unavailable.

{{required_picture}}

Require VOLPAROSSA

Block direct fallback when the required connection is unavailable.

The browser kill switch starts off. Ordinary fallback uses your regular Internet connection.

An unavailable route and a policy denial are different: a denied request must not be silently retried outside VOLPAROSSA.

What works today. What comes next.

The browser is being built toward the shared brain. Scoped tests establish parts of the foundation; the complete integration is not yet a finished browser release.
